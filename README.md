# Portfolio | 13rian Vargas

Personal portfolio website showcasing my projects, skills, and professional experience. Built with performance and interactivity in mind.

🔗 **Live Demo:** [https://13rian-vargas.vercel.app/](https://13rian-vargas.vercel.app/)

## 🚀 Tech Stack

- **Framework:** Astro 5.x
- **Styling:** Tailwind CSS 4.x
- **Language:** TypeScript
- **Runtime:** Bun
- **Interactions:** Native JS + CSS 3D Transforms

## ✨ Key Features

- **Interactive 3D Identity Card:** A unique, physics-aware 3D card built with custom CSS transformations and device orientation support.
- **Dynamic Water Ripple Background:** A custom interactive background system that responds to user clicks with performant CSS-based water ripples.
- **Advanced i18n:** Full internationalization support for English, Spanish, French, and Portuguese, managed through a custom translation system.
- **Dynamic Project Sourcing:** Projects are dynamically fetched from the GitHub API, displaying real-time stars, languages, and metadata.
- **Modern Theme Architecture:** Seamless dark/light mode transition using CSS variables and local storage persistence.
- **Performance Optimized:** Achieving near-perfect Lighthouse scores through Astro's partial hydration and static site generation.

## 🛠️ Project Structure

- `src/components/sections`: Modularized UI sections.
- `src/i18n`: Robust translation utilities and dictionaries.
- `src/layouts`: Responsive base layouts.
- `public/icons/flags`: SVG assets for internationalization.
