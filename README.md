# Portfolio | 13rian Vargas

Personal portfolio website showcasing my projects, skills, and professional experience. Built with performance and interactivity in mind.

## 🚀 Tech Stack

- **Framework:** Astro
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Runtime:** Bun

## ✨ Features

- **Interactive 3D Business Card:** Custom CSS 3D transformations with device-aware interactions.
- **Internationalization (i18n):** Full support for English, Spanish, French, and Portuguese.
- **Dark/Light Mode:** Automatic theme detection with manual toggle.
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Animations:** Smooth transitions and interactive elements using native CSS and JS.

## 🛠️ Development

To start the development server:

```bash
bun run dev
```

To build for production:

```bash
bun run build
```
